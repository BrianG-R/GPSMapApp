# App Security Improvement Program - GPSMapApp

## 1. Objetivo
Mantener y mejorar continuamente la seguridad de la aplicación GPSMapApp, reduciendo vulnerabilidades y mejorando las prácticas de desarrollo seguro.

## 2. Revisión Periódica
- Auditorías semestrales con MobSF.  
- Verificación de claves API y permisos de ubicación.  
- Actualización de dependencias y SDK mínimo.

## 3. Métricas de Seguridad
- Cantidad de vulnerabilidades corregidas.  
- Porcentaje de dependencias seguras.  
- Cumplimiento de OWASP Mobile Top 10.

## 4. Plan de Acción Futuro
- Integrar análisis estático en GitHub Actions.  
- Agregar análisis dinámico automatizado con emulador.  
- Documentar cada nueva versión con cambios de seguridad.

## 5. Resultados Esperados
- Mantener riesgo bajo (score ≥ 80 en MobSF).  
- Asegurar comunicación 100% HTTPS.  
- Garantizar protección de datos y cumplimiento de privacidad.
